# Go2-W Nvblox Live Test

This page is intentionally short so future students have one daily workflow to
follow.

- Use `docs/workflow.md` for live RViz, replay, recording, inspection, and the
  optional Nvblox commands.
- Use `docs/go2w_current_sensor_graph_status.md` for the current robot/sensor
  graph status and the reason Nvblox is optional until a stable dynamic
  `odom -> base_link` source exists.

Keep this repository read-only with respect to robot motion. Do not add Nvblox
or RViz launch paths that publish command/control topics.
